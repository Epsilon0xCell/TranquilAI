Compartment one: the script

What it is, honestly

wallpaper_generator.py is a single Python file for macOS, Python 3.9 or newer. It takes a plain prompt, such as a serene mountain landscape at sunset, and ends with a new desktop wallpaper set on the screen.

Tied tag, in the author own verdict: he recommends the tool chiefly as a preview aid before upscaling and building a proper collection by hand, suggests Upscayl for upscaling, and points purists toward Wallhaven and Alphacoders Wallpaper Abyss instead. No praise is invented here.

Compartment two: the run

Prompt to picture, in order

With a GOOGLE_API_KEY in a .env file, and GEMINI_API_KEY accepted as the alternate name, Gemini model gemini-2.0-flash-exp rewrites the prompt with detail and a no text instruction, unless --private is passed, in which case no prompt goes to Gemini at all.

Pollinations then renders the image with its Flux model, defaulting toward 5120 by 2880. Post processing adjusts brightness adaptively, nudges contrast and colour, reduces light noise, and sharpens gently, unless --no-enhance is set.

Tied tag: in private mode the printed Pollinations address still exposes the prompt in terminal scrollback.

Compartment three: the switches

Small labelled tools

python3 wallpaper_generator.py --setup
python3 wallpaper_generator.py "a serene mountain landscape at sunset"
python3 wallpaper_generator.py "ocean waves" --resolution 2560x1440 --generate-only

--setup installs dependencies including requests, google-genai, and python-dotenv. --resolution takes a size such as 2560x1440. --save-dir keeps copies. --queue-dir sets the timestamped queue. --displays gives a count when auto detection is not wanted. --generate-only stops before setting. --tool chooses among wallpaper-cli, m-cli, and AppleScript, tried in that preference order under auto.
